# Gradient Descent Exercise

This exercise aims to simulate and compare two approaches to gradient descent:

1. Using only function evaluations (finite differences to estimate derivatives).
2. Using the function and its analytic gradient (auto-differentiation simulation).

Students will implement both methods, count the number of evaluations, and analyze the trade-offs between evaluation count and accuracy.

Objectives:
- Understand finite difference approximation.
- Leverage analytic gradient for efficient descent.
- Analyze the number of function calls and accuracy improvements.
- Report and compare the results.

Instructions:
- Do not modify existing code files.
- Implement classes and functions for simulation and counting evaluations.
- Run simulations with sample functions.
- Summarize the evaluation counts and accuracy.
